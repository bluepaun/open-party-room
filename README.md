# 오픈파티룸 (Open Party Room)

각자의 기기(모바일·PC)로 함께 즐기는 **멀티플레이 파티 게임 웹앱**.
같은 네트워크에 있는 사람들이 코드를 입력해 방에 모이고, 실시간으로 게임을
함께 진행합니다.

> 이 프로젝트는 [MIT 라이선스](LICENSE) 하에 오픈소스로 공개됩니다.
> 자유롭게 사용·수정·재배포할 수 있습니다.

## 게임 목록

### 🎭 라이어 게임 (3명 이상)
1명이 랜덤으로 **라이어**가 됩니다. 라이어는 자신에게만 숨겨진 제시어를
모른 채, 다른 사람들과 자연스럽게 설명합니다. 나머지 플레이어들은 순서대로
60초씩 설명한 뒤 **투표**로 라이어를 지목해요.

- 지목된 사람이 라이어면 → 제시어를 맞히려 추측 (맞히면 라이어, 못 맞추면 시민 승리)
- 아닌 사람이 지목되면 → 무사 방출, 라이어 승리

### ❓ 양세찬 게임 · 콜 마이 네임 (2–8명)
제시어 하나를 받아 **내 단어는 숨겨지고, 다른 사람들의 단어만** 보여요.
"이거 내 단어 맞아?" — 다른 사람들의 단어를 보며 내 단어를 추리해 외쳐요.

- **🔝 이마 모드**: 내 단어를 전체화면에 크게 보여주고, 다른 사람이 맞춰
  말하면 "정답" 버튼! 먼저 맞추는 순서가 등수예요.
- **✋ 손 모드**: 다른 사람들의 단어 카드를 손에 쥐고, 내 차례에 내 단어를
  입력해요. 틀리면 턴이 넘어가고, "턴 넘기기"도 가능해요.
- 제시어는 **랜덤**(그룹 선택) 또는 **출제자 지정**(심판이 직접 입력)으로.
- 시간은 제한 없이(기본) 또는 3분(라운드)으로 선택 가능해요.

## 설치 & 실행

[Node.js 20+](https://nodejs.org) 환경에서:

```bash
# 1. 의존성 설치
npm install

# 2. 개발 서버 실행
npm run dev
```

- 브라우저에서 **http://localhost:3000** 열기
- "방 만들기"로 방을 만들면 **4자리 코드**가 생기고,
  같은 네트워크의 다른 기기에서 **http://이기기의IP:3000** 으로 접속해
  "코드로 참가"하면 플레이 시작!

production 빌드는 `npm run build` → `npm run start` 입니다.
